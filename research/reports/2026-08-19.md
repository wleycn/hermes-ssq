## 今日新发现 (4 条)

### [1] NIST SP 800-22 随机性测试电池（整套标准化套件）
- 类型: 数学模型 / 随机性检验（权威标准化电池）
- 来源: NIST SP 800-22 Rev1a (2010) "A Statistical Test Suite for RNG"；Python 实现 `randomness_testsuite`(stevenang, pip) / `nistrng`(pip)；配套解读 Rukhin 2000 ApEn χ² 检验。
- 一句话可行性评估: (高潜力 + 这是把现有分散探针**升级为权威标准化电池**的最直接路径，含 15+ 项我们**完全未覆盖**的检验，纯 Python 可落地)
- 核心思路: 将每期开奖编码为比特流（如红球值 1-33 取 6-bit 二进制拼接跨期成序列），跑 NIST 全套：frequency / block-frequency / runs / longest-run / rank / FFT / non-overlapping & overlapping template / Maurer universal / approximate entropy / serial / linear complexity 等。其中 linear complexity（线性复杂度）、Maurer universal（通用统计）、template matching（模板匹配）、rank（矩阵秩）均为现有探针体系（频谱/ordinal/可见图/混沌）从未触及的角度。
- 管线对照: 现有探针 = 频谱(3 关) + 混沌(Takens/Lyapunov/样本熵) + ordinal(08-17) + 可见图(08-18) + surrogate(08-18)。NIST 是**第四类独立电池**，且与密码学 RNG 认证同口径，证据权威性最高。
- 净新增价值: **高**（在科学证据层面）。不是新预测信号（预测增益=0，符合 i.i.d.），而是把"SSQ 公平"从自研探针升级为**行业标准的权威背书**；落地成本低（pip 装包 + 编码脚本）。预期主线仍 FLAT，但证据链最密。

### [2] Recurrence Quantification Analysis（RQA 递归量化分析）
- 类型: 数学模型 / 相位空间递归探针
- 来源: Eckmann et al. 1987（递归图）；Zbilut & Webber 1992（RQA）；PyRQA(pypi) / `nolds` 可算相关量；Wikipedia "Recurrence quantification analysis"。
- 一句话可行性评估: (中-高潜力 + 相位空间递归家族，与已覆盖的可见图(振幅邻接)正交，纯 numpy/pyrqa 可落地)
- 核心思路: 对每球序列做时间延迟嵌入重建相位轨迹 → 计算递归图 R(i,j)=Θ(ε−||x(i)−x(j)||) → 量化递归率(RR)/确定性(DET)/最长对角线(Lmax)/层状性(LAM)/捕获时间(TT)。随机序列的递归结构呈特定无组织形态；偏离即提示非随机动力学结构。对红/蓝球序列分别跑 RQA，DET/Lmax 与 surrogate 对照（接 08-18 surrogate 框架）。
- 管线对照: 现有探针无"递归图/确定性"维度。可见图是"时间相邻遮挡"邻接，RQA 是"相位空间邻域递归"，二者同源图论但判据不同、互补不重叠。
- 净新增价值: **中-高**。探测"非线性递归结构"的全新家族，抗非平稳、对短序列稳健；零预测增益但证据增量明确。

### [3] Lempel-Ziv / Kolmogorov 复杂度（算法可压缩性探针）
- 类型: 数学模型 / 算法复杂度（可压缩性）
- 来源: Lempel & Ziv 1976 (LZ76/77/78)；Kolmogorov 1965；MetricGate "Lempel-Ziv Complexity"；AIP Chaos 2013 "On the non-randomness of maximum LZ complexity"。
- 一句话可行性评估: (中潜力 + 纯算法复杂度，与所有"熵/谱/图"探针**本质不同**（基于可压缩性而非统计量），纯 Python 实现无依赖)
- 核心思路: 把符号序列（如蓝球 1-16 转成符号串）按 LZ76 切短语计数 c(n)，归一化 C_LZ=c(n)/b(n) → 随机序列 C_LZ→1、周期序列→0。可与 shuffle 基线对比分离"排序结构 vs 频率结构"。这是 Kolmogorov 复杂度的可计算近似，提供"序列能否被短程序生成"的判据——比熵更强（熵相同但可压缩性不同的序列能区分）。
- 管线对照: 现有探针全是统计量（χ²/熵/自相关/度分布/递归），**无算法信息论维度**。LZ 复杂度是首个"可压缩性"家族。
- 净新增价值: **中**。正交、零依赖、可立即实现；预期 FLAT，但补"算法随机性"缺口，与 08-17 排列熵（统计熵）形成"熵 vs 可压缩性"双视角。

### [4] Transfer Entropy（传递熵 / 有向信息流）跨球位依赖检验
- 类型: 数学模型 / 跨维度因果依赖
- 来源: Schreiber 2000 "Measuring information transfer"；pyinform / JIDT 实现；PMC6131830 信息论教程。
- 一句话可行性评估: (中潜力 + 这是**首次触及"球位间有向依赖"**——弥补现有 8 模型"逐球独立边际建模"从未验证跨位依赖的空白，与 08-18 Copula 静态联合互补但不重复)
- 核心思路: 计算 T(j→i)=MI(X_i(t); X_j(t−1) | X_i(t−1))，检验红球 6 个位（或红↔蓝）之间是否存在超出"不放回互斥"的**有向时序信息流**。若某球位 lag-1 能显著降低另一球位不确定性 → 提示破坏 i.i.d. 的结构。需符号化 + 有限样本偏差校正（k-近邻/核估计）。
- 管线对照: 现有 8 模型对每球**独立**建模边际 → 均值集成 → `constrained_decode` 强制互异；**从不检验球位间是否真独立**。Copula(08-18) 看静态联合秩依赖，Transfer Entropy 看有向时序因果——角度正交。
- 净新增价值: **中**。概念上唯一针对"跨球位时序依赖"的方向；若检出显著 TE（预期无）→ 可改进组合联合合理性过滤。预测增益=0，但填补"独立性假设是否成立的验证"缺口。
