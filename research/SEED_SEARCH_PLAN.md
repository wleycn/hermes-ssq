# SSQ 种子搜索实验计划（SEED_SEARCH）

> 状态：**Phase 0 已启动（2026-11-21 Rocky 拍板）**。五条文献修订已并入正文（§11.6 标记 ✅）。
> 关联：`ARCHITECTURE.md §2 核心立场`（不预设随机，主动找规律）、§3 已证伪清单（多重比较纪律）。

## 1. 一句话目标

在 π / e / √2 / φ（黄金比例）的小数切片种子族与等量随机对照中，
寻找"从候选池选号时，历史命中与未来命中都显著高于随机基线"的种子。
用预注册闸门裁决真假，用退出机制控制长期使用，用预算边界控制资源。

## 2. 假设的三种可证伪形式

| 编号 | 假设 | 判法 | 性质 |
|---|---|---|---|
| H1 族级 | 常数切片作为种子族，历史得分分布显著高于随机种子族 | 族 max/分位数 vs 对照组 max 分布 | 廉价先筛，不构成上线依据 |
| H2 单数 | 存在某切片种子，历史 Top-K 且在验证段（未参与选择）仍显著 | 训练/验证 70/30 切分 + **SPA 检验**（White RC 保守对照） | 上线的必要依据 |
| H3 持久 | 影子部署期滚动得分不破 CUSUM 下界（"持续多期"） | 影子期逐期记录 + CUSUM | 上线的充分依据 |

裁决只认 H2+H3 同时成立。H1 单独成立不算数。

## 3. 度量定义

| 度量 | 定义 | 随机基线 |
|---|---|---|
| 主指标 red_mean_hits | 每注红球命中数均值（30 注 × 全部回测期） | 6×6/33 = 1.0909 |
| 次指标 blue_hit_rate | 每注蓝球命中率 | 1/16 = 0.0625 |
| 块剖面 | 每 100 期一个主指标均值（35 块/种子） | 供持久性/漂移分析 |

主指标优先；次指标只做交叉印证，不单独裁决。得分 = 主指标 z 值（z = (score − 1.0909) / σ_score）。

## 4. 种子空间与位数

- **种子族**：π / e / √2 / φ。用 mpmath 现算 M+d 位小数（运行时几秒级），切片 d 位、步长 1，得约 M 个种子。
- **对照组**：等量随机整数种子（与各族同数量，同口径跑）。没有对照，任何"赢家"都无法判读。
- **PRNG 口径**：`np.random.default_rng(s)`，与生产 `select_numbers` 同款；期 t 用种子 `s*3528 + t`，防跨种子流重叠。
- **位数决策**：初始 d=6 → 每族约 100 万种子。最终位数由 Phase 0 成本表 + Phase 2 裁决共同决定。
- **位数不是越多越好**：空间越大，极值陷阱越深（N 个种子最大分期望高出均值 √(2lnN)·σ；N=10⁶ 约 5.2σ，N=10⁸ 约 6.1σ），OOS 要筛的噪声越多。位数的正确上限 = "样本外验证还能筛出真信号的那个量级"，不是越大越好。

## 5. 五阶段 + 闸门 + 实验级退出

### Phase 0 — 可行性探针（预算：1 天，≤ 3h CPU）

| 子步 | 做什么 | 产出 |
|---|---|---|
| 0.1 内核正确性 | 已知种子得分 = 理论基线 ±2σ；与生产实现交叉验证 5 个种子 | 单测绿 |
| 0.2 吞吐实测 | 1000 种子计时 → 外推 1M/10M/100M 成本表 | 成本表 |
| 0.3 空分布标定 | 10 万随机种子 → 得分分布，均值/σ 与理论核对，记录实测 max-z | 极值基线 |
| 0.4 决策表 | 位数 × 族数 × 计算小时矩阵交 Rocky 拍板 | 决策表 |
| 0.5 相关种子独立性 | π 相邻切片（连续整数种子）输出流自相关检查，防相关种子破坏独立性假设 | 独立性证据 |

**Gate G0**：内核错误或成本超预算 → 停机汇报，出 Verdict（VALIDATED / PARTIAL / INVALIDATED）。

### Phase 1 — 种子族全量搜索（预算：按 Phase 0 成本表，断点续跑）

- 1.1 常数小数计算落盘（parquet）
- 1.2 全量扫描 4 族 × N 种子 + 等量对照，每 1 万种子 checkpoint，可中断续跑
- 1.3 族级比较：各族 max/分位数 vs 对照组 max 分布 → 族 p 值（Bonferroni α=0.05/4）

**Gate G1**：族不显著 → 记录 FLAT（族级），仍进 Phase 2（单个赢家要单独出庭）；显著 → 直接进 Phase 2。

### Phase 2 — 样本外验证（真裁决，预算：1 次会话）

- 2.1 预注册切分：训练 = 前 70% 期，验证 = 后 30% 期（约 1058 期）
- 2.2 Top-K（K=20 预注册）按训练得分取出 → 验证段重算
- 2.3 判据：**SPA 检验**（零假设"无候选优于随机基线"，α=0.05，bootstrap B=2000；White RC 作保守对照），且击败生产基线在验证段的得分

**Gate G2**：全失败 → 裁决 NO-SIGNAL → 归档 → **E1 终止**（这是统计上最可能的结局，也是有效结论）。有通过者 → Phase 3。

### Phase 3 — 影子部署（持久性检验，预算：≤ 120 期）

- 3.1 每期开奖后：候选种子按生产口径生成注单，**只记分，不进邮件、不投注**
- 3.2 CUSUM 监控：滚动 30 期主指标均值 vs 基线；最短任期 15 期；参数预注册（默认 h=5、k=0.5σ，60 期内误触发率 ≤5%）。**用现成库（giobbu/CUSUM 或 changepoint-online），不手写**
- 3.3 挑战者协议：每 30 期用扩增历史重跑 Phase 1-2 精化版；挑战者须在验证段胜出 margin δ（预注册）才换

**Gate G3**：切换条件 = 挑战者胜出 或 现役 CUSUM 触发（都留痕）。连续 2 次 CUSUM 触发且无挑战者 → **E2 退役归档**。任何切换都要 Rocky 单独拍板后才动生产。

### Phase 4 — 终局归档

无论哪条退出路径：全部证据、参数、代码落 `research/seed_search/`，ARCHITECTURE §3/§7 登记。

### 实验级退出（E1–E4）

| 编号 | 触发 | 动作 |
|---|---|---|
| E1 | G2 全失败 | 裁决 NO-SIGNAL，归档，终止 |
| E2 | 影子期连续 2 次 CUSUM 触发且无挑战者 | 退役种子族假设，归档，终止 |

## 6. 单种子退役机制：不是固定期数，是 CUSUM 退出 + 挑战者协议

Rocky 问：好数字持续期是固定期数，还是某种退出机制？我的设计是**后者**。

| 方案 | 机制 | 正面 | 反面 |
|---|---|---|---|
| 固定期数 | 用满 N 期强制重搜 | 简单，无状态 | 好种子被浪费，坏种子死守 N 期；N 没法选 |
| CUSUM 退出（推荐） | 滚动得分偏离基线累计超 h 即退役 | 用数据说话，好种子留得久 | 噪声会误触发，需阈值控制误触发率 |

配套两条防误杀：
- **最短任期 15 期**：样本太小的波动不算数。
- **挑战者协议每 30 期**：即使不触发，也定期用扩增历史重搜；挑战者必须验证段胜出 margin δ 才换，防频繁换种子追噪声。

"CUSUM"是累积和控制图：把每期得分相对基线的偏差持续累加，累积量超过阈值 h 才判定"这个种子已经回归平庸"。误触发率由 h/k 控制，可预先设计。

## 7. 边界

| 边界 | 规则 |
|---|---|
| 数据边界 | 严格回视：t 期只能用 ≤ t−1 的开奖。影子期候选池冻结于实验启动日，不滚动 |
| 算力边界 | 每阶段预算表；checkpoint 续跑；超预算停机等 Rocky |
| 上线边界 | Phase 3 无投注、不改生产邮件；切生产需 Rocky 单独拍板 |
| 统计边界 | 预注册清单（§8）跑 Phase 1 前写死；事后不改判据 |
| 诚实边界 | 报告必含对照组的赢家数据；"唯一性"在噪声下是必然现象（极值），只有通过 G2 的唯一性才算证据 |
| 假设边界 | 只测可枚举的种子族；"存在某个不可枚举的魔数"不可证伪，不作为决策依据 |

## 8. 预注册清单（跑 Phase 1 前写死，事后不改）

- α_family = 0.05 / 4；K = 20；**SPA 检验 α=0.05，bootstrap B=2000**（White RC 作保守对照）
- 切分：训练前 70% / 验证后 30%（按期序，不随机抽）
- 主指标 red_mean_hits，基线 1.0909；次指标只交叉印证
- 对照种子数 = 各族种子数
- CUSUM：h=5，k=0.5σ，滚动窗 30 期，最短任期 15 期，误触发 ≤5%/60 期
- 挑战者 margin δ = 0.5σ（验证段 z 差）
- 影子期上限 120 期，到点必裁决

## 9. 风险表

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 计算量超预算 | 中 | 进度停滞 | Phase 0 实测成本表；断点续跑；多核并行 |
| 极值赢家是噪声（统计上最可能） | 高 | 白跑 | 这正是实验要证明的结论；预注册 OOS 闸门防止误上线 |
| 事后想改判据（cherry-pick 诱惑） | 中 | 结论失真 | 预注册清单，改判据=重跑 |
| PRNG 流重叠污染 | 低 | 得分失真 | 期种子 = s×3528+t；0.1 交叉验证 |
| "魔数不在族内"的失落 | 中 | 情绪影响 | 假设边界写死：不可枚举不可测 |

### 11.1 直接相关：种子作为调参参数的严格分析

| 来源 | 要点 | 对我们的影响 |
|---|---|---|
| Binh Ho, "Is the random seed a tuning parameter?"(callmequant, 2026-10) | 核心定理：试 k 个种子，最优期望 ≤ μ + σ√(2log k)。**种子不是调参**——所有种子同分布，只有一次可条件化的抽取；用同一批数据既选种子又报性能 = 有偏（Proposition 1）。合法用法二选一：多种子平均（seed averaging，方差 1/m 递减）或多种子多启动+验证集选优 | ① 我计划的极值陷阱 √(2lnN) 与定理完全一致，Phase 0 空分布标定可用它做理论核对。② **Remarks 警告：相关种子（1,2,3,…连续切片）在旧生成器上独立性不可想当然** → Phase 0 必须加"π 相邻切片种子输出流自相关"探针 |
| backtester.run, "Random Search for Strategy Optimization" | 预算制搜索；Bergstra & Bengio 2012：参数重要性不均时随机搜索优于网格；**任何搜索方法，赢家必须拿搜索没见过的新数据重测**（walk-forward/OOS） | ③ 计划已含 OOS 验证（Phase 2），方向被独立确认。④ π 切片=类网格遍历、随机对照=随机搜索，两者比较本身可引用 Bergstra-Bengio 论证 |
